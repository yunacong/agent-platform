# 学习期规则与 SOP（Learning Phase Rules）

> 目的：避免“瞎调”导致效果波动，给建议提供可解释的 SOP 引用。

## 1. 什么是学习期（概念）
学习期：系统对新计划/新素材/新定向进行探索与收敛的阶段。此阶段指标波动大，过度频繁调整会让系统反复重置学习，导致 CPA/ROAS 更不稳定。

## 2. 常见触发学习期的操作（会重置/延长学习）
- 大幅调整预算（例如 >20%）
- 大幅改出价策略/优化目标
- 频繁开关计划/改定向/改版位
- 频繁更换素材或一次性换太多
- 大幅修改落地页/转化链路

## 3. 学习期的“红线”
- 学习期前 24–72 小时：除非严重异常（如花费暴涨/转化为0/审核异常），不建议大改
- 同一计划每日调整次数建议 ≤ 1
- 预算调整建议“小步快跑”：10%–20% 梯度，而不是翻倍/砍半

## 4. 学习期 SOP（建议输出模板）
当模型判断“处于学习期”时，建议优先输出：
1) 观察建议：再观察 X 小时/补充到 Y 次点击/转化后再判断
2) 护栏设置：设置 CPA/ROAS 上限，避免烧穿
3) 只做必要操作：排查审核/素材链接/落地页错误等硬故障
4) 分组策略：新计划用小预算探索，稳定计划保基本盘

## 5. 什么情况下可以在学习期也必须出手？
- spend 异常暴涨且 revenue 不涨（疑似浪费）
- 转化链路故障（支付/表单错误率上升）
- 审核/投放状态异常（停投/限流）
- 预算分配明显错误（预算集中到低ROAS组合）
