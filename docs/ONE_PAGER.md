# ONE_PAGER｜运营/投放诊断 Agent 平台（Project 1）

## 1. 背景
运营/投手每天看盘、查数、写日报，依赖经验，诊断耗时且难复用；结论常缺少证据链，难以复盘。

## 2. 目标（Success）
- 诊断耗时下降
- 证据可追溯率提升（每条结论都能引用到数据切片/规则命中）
- 建议可执行率提升（动作清晰、带阈值与验证方式）
- 误导率下降（明确不确定性与假设）

## 3. 非目标（Not now）
- 不做真实下发投放（先只做“建议 + 导出”）
- 不做全量 BI 平台替代
- 不追求全行业通用，先打透典型场景

## 4. 输入 / 输出
- 输入：指标数据（CSV）+ 业务上下文（活动、预算、素材变更等）
- 输出：异常诊断 + 可执行建议 + 证据引用 + Markdown 导出

## 5. MVP 范围（Day14 前）
- 离线样例数据上传
- 覆盖 3 类异常：流量异常 / 转化异常 / 成本异常（Day2 定义口径）
- Dify：workflow 编排 + 调用 tools + 输出模板

## 6. 建议格式（固定）
- 问题：指标+维度+对比基线
- 证据：数据切片/规则命中
- 可能原因：2-3 条（标注置信度）
- 建议动作：动作+对象+阈值/范围
- 预期影响：对 CTR/CVR/CPA/ROAS 的方向性
- 验证方式：看哪些指标、观察多久
- 风险提示：需要补充的数据/可能误导点
